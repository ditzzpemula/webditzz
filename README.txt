FAHRI CLOUD STORAGE
====================

Isi:
- index.html
- style.css
- app.js
- firestore.rules
- storage.rules

CARA PASANG:
1. Buat project Firebase.
2. Aktifkan Authentication > Email/Password.
3. Aktifkan Firestore Database.
4. Aktifkan Storage.
5. Buat Web App di Firebase.
6. Salin firebaseConfig ke app.js.
7. Pasang Firestore Rules dari firestore.rules.
8. Pasang Storage Rules dari storage.rules.
9. Upload folder ini ke hosting static seperti Firebase Hosting, Vercel, Netlify, atau GitHub Pages.

CATATAN:
Website tidak bisa benar-benar online tanpa konfigurasi Firebase milik kamu.
